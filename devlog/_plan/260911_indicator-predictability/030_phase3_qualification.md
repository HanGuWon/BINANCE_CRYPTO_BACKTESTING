# Phase 3 — Synthetic qualification only

Scope is outcome-blind and synthetic. The slow reference compares immutable decision, entry, exit, label, and eligibility fields against the optimized implementation for Spot and UM, 15m/1h/4h, every duration-valid horizon, and an explicit gap segment. UM fixtures include alternating positive and negative funding values; no historical funding, returns, R2B, R3, or final-holdout data is read.

Acceptance: exact field agreement, deterministic repeated receipt, explicit final-holdout `UNTOUCHED`, and no outcome process launch. This phase does not authorize historical outcomes.
