# R3 prospective context campaign plan

This docs-first phase closes the corrected R2B v7 lineage without mutating
its checkpoints, records the standalone negative-evidence synthesis, and
defines the boundary for a new prospective context campaign. No historical
holdout, R2B2, or prospective return outcome may be accessed. Subsequent
implementation is dependency-ordered: evidence portability, collector
provenance and continuity, preregistered contracts, causal materialization,
then collection-only qualification and smoke verification.

The R3 question is whether historically unavailable market-state observations
can provide causal context or gates for simple price signals. It is not a
search for a profitable combination. Public Binance data only; no private
credentials, cross-venue substitution, or retrospective threshold selection.
